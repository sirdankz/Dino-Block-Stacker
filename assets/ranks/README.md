# Rank emblems

The original transparent 24x24 pixel-art PNGs are retained here. Both ports render crisp 34x34 nearest-neighbor copies compiled into `src/xbox/ta_egg_sprites34.h`; no runtime image decoding is required.

Rating tiers use Rotten Egg, Bronze Egg, Silver Egg, Gold Egg, Platinum Egg, and Master Egg, in that order. The supplied star artwork represents Master Egg.

Generate the compiled header from these originals when changing artwork. Do not rescale an already resized export.
